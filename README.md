# yirengyao 的个人网站

原生 HTML、CSS、JavaScript，无需安装依赖或构建，可直接部署到 GitHub Pages。

- index.html：站名、介绍、文章内容及导航。
- style.css：布局、配色、响应式样式与动画。
- script.js：菜单、滚动渐入、打字、粒子和动态效果开关。
- assets/landscape.jpg：封面照片。

照片由 Ivan Rohovchenko 发布于 Unsplash：https://unsplash.com/photos/a-lake-with-trees-and-mountains-in-the-background-8fVmVlnrN5k

仓库 Settings → Pages → Deploy from a branch → main → /(root)。
页面含一篇明确标注的示例手记，可自行替换。支持键盘操作和系统“减少动态效果”偏好。
